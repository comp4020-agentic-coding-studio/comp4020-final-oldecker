# Reflections

One file per crit: `crit-8.md`, `crit-9.md` and `crit-10.md`, each in place by
that crit's cutoff. The cutoff sweep reads exactly these names, so a reflection
under any other name reads as missing.

Each answers the two standing prompts:

1. What was the breakthrough that moved the work forward?
2. What did this work change about who I want to be as a software developer?

150--300 words is plenty. They stay in the repo; they aren't part of the
deployed app.
